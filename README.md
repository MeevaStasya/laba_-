# Лабораторная работа №2 — мини-игра «Охота за сокровищем» (OWASP Top 10)

Простая веб-игра на Python/Flask с намеренными уязвимостями, скрипты их
эксплуатации и патчи в формате `diff`. Всё приложение — в одном файле `app/game.py`.

> ⚠️ Только для учёбы. Приложение заведомо небезопасно. Запускать локально
> (`127.0.0.1`) или в изолированной ВМ, в интернет не выкладывать.

## Уязвимости

| # | Уязвимость | OWASP | Где в игре |
|---|-----------|-------|-----------|
| 1 | SQL-инъекция | A03 Injection | вход в игру — можно войти Мастером без пароля |
| 2 | Хранимый XSS | A03 Injection | таблица рекордов — ник выводится без экранирования |
| 3 | IDOR / контроль доступа | A01 Broken Access Control | `/treasure/<id>` — чужой сундук по номеру |

## Запуск игры (часть 1)

```bash
pip install -r requirements.txt
python app/game.py
```
Открой в браузере **http://127.0.0.1:5000**. Игроки для входа:
`warrior / swordpw`, `mage / magicpw`, Мастер — `gamemaster / Sup3rMaster`.

## Как сломать игру (часть 2)

**Руками в браузере:**
- **SQL-инъекция:** на входе ник `gamemaster'--`, пароль любой → войдёшь Мастером и увидишь флаг `MASTER_FLAG_777`.
- **XSS:** в рекордах в поле «Ник» вставь `<script>alert('XSS')</script>` → выскочит окошко.
- **IDOR:** войди как `warrior`, открой `http://127.0.0.1:5000/treasure/1` → увидишь сундук Мастера.

**Скриптами (при запущенной игре, во втором терминале):**
```bash
python exploits/exploit_sqli.py
python exploits/exploit_xss.py
python exploits/exploit_idor.py
```

## Как починить (часть 3)

```bash
patch -p1 < patches/01-sqli.diff     # параметризованный SQL-запрос
patch -p1 < patches/02-xss.diff      # экранирование ника (html.escape)
patch -p1 < patches/03-idor.diff     # проверка владельца сундука -> 403
```
После патчей и перезапуска игры все три скрипта сообщают о неудаче — уязвимости закрыты.
